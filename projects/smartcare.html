Overview

A modern healthcare patient management system built with React, TypeScript and Supabase: patient scheduling, health records and care coordination in one place.

What it does

  • Patient dashboard: medical records, appointments, profile
  • Doctor dashboard: schedules, patient records, appointments
  • Admin dashboard: doctors, patients, appointments and reports
  • Sign-in, sign-up and password reset through Supabase Auth
  • Automated appointment and system notifications
  • Full light and dark themes

How it’s built

A Vite and React single-page app with Supabase for the backend, auth and database, deployed on Vercel.

  • Tailwind CSS and shadcn/ui for the interface
  • TanStack Query for server state
  • Recharts for the report charts
  • Supabase edge functions and migrations

My role

As project manager, I kept the team’s sprints on track and bridged developers and stakeholders.
