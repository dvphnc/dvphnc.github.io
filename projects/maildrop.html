Overview

MailDrop is a pay-per-send email delivery platform built for simplicity. No accounts, no subscriptions: fill a form, pay with PayPal, and your email lands in seconds, with a file attached if you need it.

The problem

You don’t need a full email marketing suite to send one meaningful message. Every send is gated behind a PayPal payment, so sending a one-off email feels intentional and nothing goes to waste.

What it does

  • A split send form with a live preview that updates as you type
  • A PayPal payment flow (sandbox mode, no real money)
  • Drag and drop attachments
  • An email history dashboard with search and delete
  • A dark, minimal landing page built to get out of the way

How it’s built

A full-stack Laravel and Vue 3 application with Inertia.js, PayPal Sandbox API integration and real email delivery.

  • Inertia.js for an SPA feel without a separate API
  • Resend API for delivery over HTTP, so no SMTP blocks
  • SQLite for a lightweight database
  • A Docker production build, hosted on Render

Result

It started as a school activity, a PayPal integration exercise for class. It turned into one of the things I’m most proud of building.
