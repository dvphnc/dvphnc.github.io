Burp Suite Fundamentals

The platform that redefined web security testing

min read · joana daphne sy

Burp Suite is the gold standard integrated platform for web application security testing, used by pentesters, bug bounty hunters, and red teams worldwide.

Core Components

ToolPurpose
ProxyIntercept & modify HTTP traffic
RepeaterManually edit and resend requests
IntruderAutomate brute-force, fuzzing, and payload attacks
ScannerAutomated vulnerability detection (Pro)
SequencerAnalyze randomness of tokens & sessions

Intruder Attack Types

TypeUse Case
SniperFuzz one parameter at a time
Battering RamSame payload in multiple positions
PitchforkDifferent payloads per position
Cluster BombAll combinations (brute force)

Best Practice: Pair with DVWA

DVWA (Damn Vulnerable Web Application) is the perfect legal playground to master Burp Suite.

  • Practice SQLi, XSS, Command Injection, File Upload
  • Learn how real vulnerabilities behave
  • Safe, isolated, fully controllable environment

Quick Setup Reminder

  • Browser → Proxy: 127.0.0.1:8080
  • Install Burp CA certificate
  • Turn Intercept ON → Capture → Send to Repeater/Intruder
  • Never test without permission
